# MatchLab

A C++ football match analysis system designed to record match results,
manage teams, and analyze football statistics.

## Features

- Match management
- Team statistics
- League table calculation
- Match search and filtering
- Data persistence

## Technologies

- C++17
- CMake
- Git
- GitHub

## Project Status

Currently under development.

## Goals

The goal of MatchLab is to build a modular football analysis application
while practicing object-oriented programming, data management,
algorithm design, and software development workflows.
